# Legal and ethical scope

This document explains project policy; it is not legal advice.

## Independent interoperability purpose

DAW Project Cleaner is independently written to help lawful users inventory
their own project archives. It reads limited project metadata necessary to
identify media references. It does not copy application expression or provide a
substitute DAW.

The public repository contains no Steinberg software, source code, binary,
licensed media, SDK content, manuals, activation component or user project
corpus. Development does not require modifying or decompiling an application
binary.

## EULA boundary

Steinberg's published EULA states that decompilation, disassembly and source-code
determination are prohibited unless permitted by law, and separately prohibits
modifying software binary code to bypass activation or licensing. This project
does neither. See the official [Steinberg EULA](https://download.steinberg.net/legal/eula/EULA_English.html).

## European interoperability framework

Directive 2009/24/EC includes provisions allowing a lawful user to observe,
study or test a program's functioning during authorized use, and Article 6 sets
conditions for obtaining information indispensable to interoperability of an
independently created program. Those conditions include necessity, lawful access,
limited scope and restrictions on later use/disclosure. See the official
[EUR-Lex text](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32009L0024).

Applicability depends on facts and jurisdiction. The maintainers do not claim
that every possible contribution or use is lawful. Contributors must obtain
their own advice and rights.

## Project rules

- Interoperate only with files the user is authorized to access.
- Do not bypass authentication, activation, licensing, encryption or access
  controls.
- Do not inspect, patch or distribute application binaries.
- Do not publish customer projects, audio, private paths or licensed content.
- Collect and expose only information needed for the independent utility.
- Do not use compatibility findings to create a substantially similar DAW.
- Keep third-party names factual and preserve the non-affiliation notice.
- Unknown formats and all write operations must fail closed.

## Trademarks

Cubase and Nuendo names are used solely to identify project-file compatibility.
No logo, trade dress or claim of endorsement is used. See [NOTICE](../NOTICE.md).

## Future write capability

Automatic project modification would materially change the risk profile. It
must not be merged into the public release without fresh technical, security and
legal review, plus exact application validation and recovery design.
